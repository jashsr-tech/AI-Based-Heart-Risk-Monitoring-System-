1. HRV METHODOLOGY AUDIT & CAUSALITY PROOF
------------------------------------------------------------------------------
Mathematical Specification in Stage 3 implementation:
  HRV_i = sqrt( 1/M * sum_{j=0}^{M-1} (RR_{i-j} - mean_RR_i)^2 )
  where M = min(5, N_preceding_valid_beats) with gating condition M >= 3.
  If M < 3 (e.g. beats 0 and 1 of a recording), HRV_i = NaN.

Causality & Temporal Leakage Verification:
  - Strict Lookback: Only intervals {RR_i, RR_{i-1}, ..., RR_{i-M+1}} enter the FIFO buffer.
  - Future beats (RR_{i+1}, RR_{i+2}) are NEVER accessed in the HRV calculation.
  - Temporal causality is 100% strictly preserved.

Ectopic Beat Handling in Stage 3:
  - The current Stage 3 implementation computes short-term RR variability across ALL
    preceding valid beats in the queue (including ectopic beats and coupling pauses).
  - When a premature beat occurs, RR_pre is abbreviated and followed by a compensatory
    pause. This causes local RR standard deviation to sharply spike:
      Class 0 HRV Mean: 0.0697 s (Median: 0.0292 s)
      Class 1 HRV Mean: 0.1830 s (Median: 0.1456 s)
  - Thus, in Stage 3, HRV acts as an acute 'Rhythm Perturbation / Prematurity Indicator'
    rather than steady-state autonomic parasympathetic tone (sinus NN SDNN).

6. SHORTCUT LEARNING ASSESSMENT: CAN THE MODEL EXPLOIT MISSINGNESS?
------------------------------------------------------------------------------
Findings on Missingness as a Feature:
  * P_Valid rate : Class 0 = 66.2%, Class 1 = 22.0% (Missing in 78.0% of Class 1!)
  * PR_Valid rate: Class 0 = 65.9%, Class 1 = 14.6% (Missing in 85.4% of Class 1!)
  * SHORTCUT RISK: In an unregularized Decision Tree, splitting on 'PR_Valid == 0' or
    'P_Valid == 0' immediately isolates a massive fraction of Class 1 beats (PVCs).
  * However, relying SOLELY on missingness fails in two critical clinical scenarios:
      1. False Positives: Noisy sinus beats, baseline wander, or lead vector orientation
         where P-wave is isoelectric (Class 0) would be misclassified as Class 1!
      2. False Negatives: Premature Atrial Contractions (PACs, symbol 'A' in Class 1)
         frequently DO have P-waves (abnormal morphology) and would be missed!
  * CONCLUSION: The model MUST combine timing prematurity (RR/HR), morphology
    (QRS duration widening, ST shift), and missingness signals simultaneously.
    Tree depth regularization and feature subsampling (Random Forest max_features='sqrt')
    are essential to force the ensemble to evaluate morphology alongside timing.
