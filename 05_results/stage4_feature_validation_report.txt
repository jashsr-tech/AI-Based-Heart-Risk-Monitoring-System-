   Window size: K = 10 preceding valid intervals. Minimum gating: M >= 3 beats.
   Ectopic intervals included -> represents local rhythm perturbation / dispersion.
   Causality certified: zero future intervals accessed (only intervals up to beat i used).

4. DATASET COLUMN AUDIT (25 COLUMNS IN V2 DATASET)

Audit of 25 Columns in 'mitbih_beat_features_mapped_v2_k10.csv':
  * Explanation of 25th Column: Stage 3 contained 24 columns. To ensure complete
    auditability and mathematical reproducibility without destroying historical data,
    the original K=5 population HRV was preserved as 'HRV_K5_Old' (+1 column),
    while 'HRV' was updated to K=10 sample SDNN. Total columns = 24 + 1 = 25.

Complete Column Categorization:
  Group 1: 9 Numerical ML Features (Inputs to Machine Learning Models):
     1. RRInterval      (float, s) : Preceding RR interval (s_i - s_{i-1})/fs. Primary timing feature.
     2. HRV             (float, s) : K=10 rolling sample standard deviation (SDNN). Rhythm dispersion.
     3. QRSDuration     (float, s) : Depolarization width (t_S - t_Q). Hallmark of ventricular ectopy.
     4. QTInterval      (float, s) : Total ventricular activation/recovery duration (t_Tend - t_Q).
     5. STSegment       (float, mV): Early repolarization amplitude at J + 60 ms relative to PR baseline.
     6. PRInterval      (float, s) : AV conduction time (t_R - t_P_onset). NaN when P-wave unidentifiable.
     7. PAmplitude      (float, mV): Peak atrial depolarization voltage. NaN when unidentifiable.
     8. RAmplitude      (float, mV): Peak dominant ventricular depolarization voltage.
     9. TAmplitude      (float, mV): Peak ventricular repolarization voltage.

  Group 2: 6 Missingness Indicators (Boolean 0/1 Inputs for Experiments C/D):
    10. P_Valid         (int: 0/1) : 1 if P-peak detected; 0 if unidentifiable / NaN.
    11. PR_Valid        (int: 0/1) : 1 if PR interval valid; 0 if unidentifiable / NaN.
    12. QRS_Valid       (int: 0/1) : 1 if QRS duration valid; 0 if unidentifiable / NaN.
    13. ST_Valid        (int: 0/1) : 1 if ST segment valid; 0 if unidentifiable / NaN.
    14. QT_Valid        (int: 0/1) : 1 if QT interval valid; 0 if unidentifiable / NaN.
    15. Baseline_Valid  (int: 0/1) : 1 if dynamic isoelectric PR baseline certified; 0 if NaN.

  Group 3: 9 Metadata, Identifiers & Non-ML Columns (STRICTLY EXCLUDED from Feature Matrix X):
    16. Record          (int)      : Tape identifier (100 to 234). EXCLUDED to prevent patient leakage.
    17. Subject_ID      (str)      : Verified subject ID (Subject_100 to Subject_234). EXCLUDED from ML.
    18. Partition       (str)      : Data partition (Train_Dev, Validation, Independent_Test). EXCLUDED.
    19. Sample_Idx      (int)      : Raw signal sample offset at 360 Hz. EXCLUDED to prevent temporal memorization.
    20. R_Time          (float, s) : Elapsed time coordinate from start of tape. EXCLUDED from ML.
    21. Annotation_Symbol(str)     : Original MIT-BIH cardiologist beat symbol. EXCLUDED to prevent label leakage.
    22. AAMI_Class      (str)      : Intermediate AAMI category (N, S, V, F). EXCLUDED from ML.
    23. HeartRate       (float, bpm): 60.0 / RRInterval. EXCLUDED from ML to eliminate rho = -1.0 redundancy.
    24. HRV_K5_Old      (float, s) : Legacy Stage 3 K=5 population HRV. EXCLUDED from ML (audit reference only).

  Group 4: 1 Target Column (Supervised Label):
    25. Label           (int: 0/1) : Binary classification target (0 = AAMI N; 1 = AAMI S, V, F). NEVER an input.

  Data Leakage Prevention Certification:
    * Zero Label Leakage: Label, AAMI_Class, Annotation_Symbol are excluded from X.
    * Zero Subject Leakage: Record, Subject_ID, Partition are excluded from X.
    * Zero Spatiotemporal Leakage: Sample_Idx, R_Time are excluded from X.
    * Zero Mathematical Collinearity: HeartRate is excluded from X.
    * Clean Input Dimensions: X has 2 features (Timing), 7 features (Morphology), 9 features (Combined No Ind), or 15 features (Combined With Ind).

  RR Interval Temporal Causality Certification:
    * For every beat i, RRInterval = (s_i - s_{i-1}) / fs, strictly using the PRECEDING beat interval.
    * The subsequent interval (s_{i+1} - s_i) / fs occurs in the future and is NEVER an input feature.
    * HRV buffer only collects preceding intervals {RR_i, RR_{i-1}, ..., RR_{i-M+1}} (strict lookback).
