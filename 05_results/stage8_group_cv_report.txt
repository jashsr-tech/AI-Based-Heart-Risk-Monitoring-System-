11. METHODOLOGICAL ADDENDUM & FORMAL DOCUMENTATION CORRECTIONS:
=====================================================================================
1. Metric Terminology:
   - 'Global Calibration Gain' is formally corrected to 'Improved Discrimination/Ranking Performance'.
   - Average Precision (AP) measures minority-class (Class 1) ranking performance in precision-recall space.
     It does not evaluate probability calibration (e.g., Brier score or calibration curves).
2. Class Label Definitions:
   - Class 0 is defined as the 'selected AAMI N group' (including normal sinus N, bundle branch blocks L and R,
     and escape mechanisms e and j). It must not be described exclusively as normal sinus beats.
   - Class 1 is defined as 'selected non-normal beat classes' (SVEB, VEB, and fusion F).
3. Inter-Patient Variance & Morphology Hypotheses:
   - Fold-to-fold performance variations (e.g. Sensitivity swings from 32.14% in Fold 1 to 85.49% in Fold 2)
     demonstrate high inter-patient heterogeneity.
   - Any discussion regarding PVC morphology differences, late-cycle coupling, or bundle branch conduction delays
     is recognized strictly as a set of possible hypotheses requiring further morphological investigation,
     not established clinical findings. Generalization must not be overstated.
4. Statistical Distinction:
   - Fold-Wise Mean (N = 5): Unweighted arithmetic mean across folds, weighting each patient fold equally.
   - Pooled Out-of-Fold (N = 66,679): Sample-weighted global evaluation, weighting every heartbeat equally.
